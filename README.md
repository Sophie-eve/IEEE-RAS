# IEEE Robotics and Automation Society (IEEE RAS)

> **Official Web Platform & Information Portal**  
> Designed & Developed by **Shailja Singh**  
> Department of Mechanical Engineering (Electric Vehicles / E.V.)

A modern, responsive, production-quality web platform for the **IEEE Robotics and Automation Society (IEEE RAS)**. Built to communicate the society's mission, technological frontiers, flagship conferences, archival research publications, global chapters, and pathways for students and professionals.

---

## 🌟 Key Features

- **Autonomous Society Hero**: Sleek, modern centered design highlighting IEEE RAS's scope in embodied physical intelligence, global chapters, technical committees, and publications.
- **8 Dedicated Pages**:
  - **Home**: Society overview, mission, core domains, global impact metrics, and interactive pathway finder.
  - **About**: History, governance, leadership, and distinction between Robotics and Automation paradigms.
  - **Technologies**: Deep technical dives into Autonomous Manipulation, Human-Robot Interaction (HRI), Aerial Robotics, Soft Robotics, Medical Robotics, Bio-inspired Systems, Swarm Autonomy, and Industrial Automation.
  - **Events & Conferences**: Interactive filtering across ICRA, IROS, CASE, Humanoids, and regional symposiums with paper deadlines, locations, and modal details.
  - **Research & Technical Committees**: Comprehensive directory of 35+ technical committees with chairs, focus areas, and working groups.
  - **Publications & Journals**: Details on flagship archival periodicals (T-RO, RA-L, T-ASE, RAM) with impact factors, indexing, and author submission guidelines.
  - **Community & Chapters**: 3D interactive Earth network globe powered by Three.js showing international research hubs, student chapters, and regional hubs.
  - **Get Involved**: Career stage pathways, membership benefits, volunteering, student travel grants, and competition sponsorships.
- **Interactive 3D Community Globe**: Custom Three.js geodesic network visualizing global RAS chapters across continents.
- **Student & Member Pathway Finder**: Role-based guided wizard connecting visitors to relevant resources, grant opportunities, and committee memberships.
- **Responsive & Accessible**: Fully optimized for mobile, tablet, and ultra-wide displays with dark mode and semantic HTML.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + Vanilla CSS
- **3D Graphics**: Three.js (`three`, `@types/three`)
- **Icons**: Lucide React (`lucide-react`)
- **Routing**: React Router v7 (`react-router-dom`)

## 🚀 Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18+ recommended) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/Sophie-eve/IEEE-RAS.git

# Navigate to the project directory
cd IEEE-RAS

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open https://ieee-ras-three.vercel.app/ in your browser.

### Production Build & Preview

```bash
# Build the optimized production bundle
npm run build

# Preview the production build locally
npm run preview
```
